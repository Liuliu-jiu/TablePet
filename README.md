# 项目介绍
这是一个基于Qt框架开发，用于娱乐的桌面宠物程序

# 项目描述
它是一个可以在屏幕上行走的小猫宠物程序，它可以在用户办公时提供情绪价值，解决用户烦闷问题，使得用户放松，用户可以通过鼠标与它互动，同时能够查看系统的相关性能，如内存情况

# 安装及卸载方法
通过安装包安装(安装推荐创建快捷方式)，卸载通过控制面板找到TablePet version <版本号>卸载，如TablePet version 2.0

# 使用方法
## 1.状态切换功能
1.1 通过双击小猫切换状态(行走/站立)

## 2.拖拽功能
2.1 左键单击小猫不放，即可拖拽

## 3.右键菜单功能说明
### 3.1 行走碰壁触发受伤状态
当处于行走状态碰到边界时会播放受伤动画

### 3.2 性能窗口
可查看系统的内存，CPU使用情况  
注意：由于性能窗口与任务管理器的更新频率存在差异，因此计算出来的百分比不一定与任务管理器的百分比相同

### 3.3 设置
目前处于demo状态

### 3.4 关闭
关闭桌面宠物程序

# 常见问题
## 平台支持
### Q.支持哪个平台
A.仅支持windows平台

### Q.提示日志文件无法打开
A.查看路径是否在系统盘，如C:\Program Files，使用安装包安装时请将路径转移至其它盘

# 编译指南
## 环境
Qt版本：Qt6.8.3  
项目构建工具：Cmake(建议 >= 3.20)  
编译器：mingw  
版本控制工具：git

## 步骤
### windows平台
#### 安装环境
1.推荐使用Qt官方在线安装器安装Qt creator  

#### 拉取代码
git clone git@github.com:Liuliu-jiu/TablePet.git  

#### 项目构建
1.打开Qt Creator  
2.文件->打开文件或项目  
3.打开Cmake文件  
4.选择mingw编译器  
5.点击configure Project
