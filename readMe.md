# 项目介绍
这是一个基于Qt框架开发，用于娱乐的桌面宠物程序

# 项目描述
它是一个可以在屏幕上行走的小猫宠物程序，它可以在用户办公时提供情绪价值，解决用户烦闷问题，使得用户放松，用户可以通过鼠标与它互动，不仅可以自定义属于自己的模型，同时能够监视系统的相关性能，如内存情况等

# 安装及卸载方法
## windows平台
安装：通过安装包安装(安装推荐创建快捷方式)  
卸载：通过控制面板找到TablePet version <版本号>卸载，如TablePet version 2.0

## Linux平台
安装：下载后解压缩，在当前文件夹双击TablePet2或使用./TablePet2命令运行可执行文件  
卸载：通过rm命令卸载下载的文件夹即可

# 使用方法
## 1.状态切换
1.1 通过双击小猫切换状态(行走/站立)

## 2.拖拽
2.1 左键单击小猫不放，即可拖拽

## 3.右键菜单说明
### 3.1 行走碰壁触发特殊状态
特殊状态指的是各个模型独有的状态(如小猫模型有受伤状态，骷髅模型有攻击状态等)  
当模型没有特殊状态时，就会将该按钮隐藏  
当处于行走状态碰到边界时会播放各个模型独有的状态动画

### 3.2 性能窗口
可查看系统的内存，CPU使用情况  
注意：由于性能窗口与任务管理器的更新频率存在差异，因此计算出来的百分比不一定与任务管理器的百分比相同

### 3.3 自定义配置
允许用户制作属于自己的模型，特殊状态可不填  
图片要求：仅支持png格式，将某个状态的图片收集到一个目录中，通过按钮导入，图片命名只能为数字，将数字当作索引，从1开始，依次递增，比如1.png，2.png....

### 3.4 设置
#### 常规
可以设置模型的行走，站立等频率，设置模型生成方向，位置，状态，也可以设置是否开机自启动，是否在linux下创建快捷方式

#### 模型
可以通过单选框切换已加载的模型

#### 性能窗口设置
通过多选框显示/隐藏某个性能控件

### 3.5 关闭
关闭桌面宠物程序

# 常见问题
## Q.支持哪个平台
A.支持windows和linux平台

## Q.提示日志文件无法打开
A.查看路径是否在系统盘，如C:\Program Files，使用windows安装包安装时请将路径转移至其它盘

## Q.运行期间将加载的模型文件删除后，下次运行时无法显示窗口
A.前往程序根目录，双击appConfig.json，将userSelectedModelName字段值改为其它模型名,比如"userSelectedModelName": "小猫"改为"userSelectedModelName": "骷髅士兵"  
模型名在程序根目录除appConfig之外的.json文件查看modelName(模型名)的字段值得到，比如"modelName": "小猫",模型名就是小猫，在配置窗口输入时不带双引号

# 编译指南
## windows
### 环境
Qt版本：Qt6.8.3  
项目构建工具：Cmake(建议 >= 3.20)  
编译器：mingw  
版本控制工具：git

###  步骤
#### 安装环境
1.推荐使用Qt官方在线安装器安装Qt creator  

#### 拉取代码
git clone git@github.com:Liuliu-jiu/TablePet.git  

#### 项目构建
1.打开Qt Creator  
2.文件->打开文件或项目  
3.打开Cmake文件  
4.选择mingw编译器  
5.点击configure Project

## Linux
### 环境
Qt版本：Qt6.8.3  
项目构建工具：Cmake(建议 >= 3.20)  
编译器：gcc  
版本控制工具：git

###  步骤
#### 安装环境
##### 手动配置
使用qt官方下载器下载后，需要添加环境变量，在 ~/.bashrc文件末尾告诉系统qt的bin目录和lib目录在哪  
export PATH="/opt/Qt/6.5.0/gcc_64/bin:$PATH"  
export LD_LIBRARY_PATH="/opt/Qt/6.5.0/gcc_64/lib:$LD_LIBRARY_PATH"  
将/opt/Qt/6.5.0/gcc_64/bin和/opt/Qt/6.5.0/gcc_64/lib替换为qt的bin目录和lib目录的实际路径

#### 拉取代码
git clone git@github.com:Liuliu-jiu/TablePet.git  

#### 项目构建
1.打开Qt Creator  
2.文件->打开文件或项目  
3.打开Cmake文件
